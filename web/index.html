Engine

This browser build ships its own engine: a negamax search with alpha-beta pruning, quiescence and piece-square tables, running in a web worker so the board never freezes. The desktop app additionally drives Stockfish when one is installed.

About

Chess Coach is a PySide6 + python-chess desktop trainer with a 1–100 adaptive opponent, a live move coach and twelve interactive lessons. This page is the browser build of the same app, sharing its palette, board themes, lessons and coach grading.
